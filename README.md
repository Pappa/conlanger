# Conlanger

Automated conlang creation using [GANs](https://en.wikipedia.org/wiki/Generative_adversarial_network) (generative adversarial networks).

This is a personal project that may go nowhere useful, but the aim is a full automated pipeline.

- generate plausible phoneme inventories and lexicons
- generate a proto-language with realistic grammar
- evolve the language with sound-change rules
- produce formal grammar documents, audio, and other artifacts.
