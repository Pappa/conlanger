# Correction pass: flatten nested sets in env / exception

Target cluster: `nested_brackets` — nested `{…}` in **env** or **exception** only (~16 inventory rows at 2026-08-12 baseline; **45** rows index-wide on 2026-08-19 inventory).

Spawned from [spike 67](67-spike-nested-sets.md). Findings: [nested-sets-inventory.md](../research/nested-sets-inventory.md) §4.2–4.4. **Placement:** [spike 85](85-spike-nested-set-flatten-prototype.md) — **parse-time at slot P4** (after `resolve_catch_all_else_rules`), not compile-time.

## Problem

Index encodes env/exception alternations with nested braces, e.g.:

- `_ə{(C){p,kʷ},m,w}` (`index_diachronica_original.html:1903`)
- `_{s,({m,j,w})V}` (`index_diachronica_original.html:5509`, `:5510` — else copies this env to exception)
- `{{C[-fr,+bk,-hi,-lo],K}ʷ,w}_` (`index_diachronica_original.html:11552`)

ASCA 0.10.2 rejects nested `{}` of the same bracket type at lex time (`NestedBrackets`).

## What to build

1. Parse-time `flatten_nested_sets` on **env** and **exception** only (production port of spike 85 prototype). Insert at **P4**: after `resolve_catch_all_else_rules` in `IndexDiachronicaParser.parse`, so else-copied exceptions are flattened. Do not mutate `raw`.
2. Mode **union + parenthetical-in-set**: `{a,{b,c}}` → `{a,b,c}`; `({m,j,w})V` → `{mV,jV,wV}`; `_ə{(C){p,kʷ},m,w}` → `_ə{(C)p,(C)kʷ,m,w}`; `{{h,k,ŋ}n,…}` → `{hn,kn,ŋn,…}`. Leave unbalanced strings unchanged.
3. TDD on representative inventory lines; full regen + metrics. Spike 85 prototype recovered **7** env/exception rows at union-only and **+4** more with paren-in-set (`:1903`, `:5509`, `:5510`); **0** `ok` regressions.

## Policy

- ADR-0010: class-first de-condensation; preserve `raw`. Same class as medial / else / stress / feature/IPA / `series_expansions`.
- ADR-0002: YAML `env` / `exception` **do** change at parse (applier-neutral flat alternation). Do **not** flatten at compile after ticket-48 parentheticals (that would “fix” bucket D / #71).
- Else: flatten-before-else (P3) and flatten-after-else (P4) commute for complementary copies; implement P4 anyway so derived exceptions are covered. Deferred else (`:1762`/`:1763`, prev has env **and** exception) does not copy — flatten `:1762` exception in place.
