## Problem

Index encodes I/O alternations with nested braces (often editorial condensation, not cited-source notation). Examples:

| source | YAML / Index shape | Spike 85 |
|--------|--------------------|----------|
| `index_diachronica_original.html:998` | HTML `{ʔ,hₓ}` → YAML `{ʔ,h₁,h₂,h₃}` (already flat via series expansions) | no-op |
| `index_diachronica_original.html:5048` | `{{∅,∅}s,s{∅,∅}}` / `{{h₁,h₃}s,s{h₁,h₃}}` | union → **`ok`** |
| `index_diachronica_original.html:1398` | `{{s,z}(ˤ),ʒ}ʃ` | needs **union_paren** → **`ok`** |
| `index_diachronica_original.html:6193` | `{e,w{æ,i}}` | union → **`ok`** |
| `index_diachronica_original.html:2398` | `(h)ə{p,b}` (depth 1) | **unchanged** — #71 |
| `index_diachronica_original.html:1149` | `{{ɣ,ɣʷ,xʷ},x}` | **unchanged** — compile-created nesting (group mappings) |

ASCA 0.10.2 rejects nested `{}` of the same bracket type at lex time (`NestedBrackets`).

## What to build

1. Reuse production `flatten_nested_sets` from [69](69-correction-pass-flatten-nested-context-sets.md) (same **P4** hook in `IndexDiachronicaParser.parse` after `resolve_catch_all_else_rules`). Apply to each **stage string** independently. Preserve **`raw`**.
2. Mode **union_paren** (must match #69): union flatten plus parenthetical-in-set expansion for `:1398` `{s,z}(ˤ)`.
3. Do **not** flatten bucket **D** shapes — YAML depth 1; `NestedBrackets` from compile parentheticals is [71](71-grill-paren-and-parallel-set-notation.md): `(h)ə{p,b}`, `e(C){V[…]}`, `a(C){o,e}`, `{e{V…},eC{V…}}`, etc.
4. Chain malformation (`4654`, unbalanced `2173`) → leave unchanged; route to `manual_mappings` / skip, not this handler.
5. TDD + full regen; metrics in **Answer**.
