# GAN phoneme inventories plus bundled presets

Phoneme inventories are intended to be **generated by a GAN** (or successor generative model) over a tensorised inventory representation, in the spirit of the existing notebooks. Separately, the library must ship with a **fixed set of ~100 pre-generated phoneme inventories** so callers can use conlanger without running the GAN.

## Considered Options

- **GAN only at use time** — flexible; blocks “just use the library” workflows.
- **Bundled presets only** — easy UX; abandons the generative inventory stage.
- **GAN as generator + ~100 bundled presets (chosen)** — generative path remains; zero-GAN usage works.

## Consequences

- Packaging must include a curated preset inventory set (exact count ~100; curation tracked by ticket).
- Public APIs should allow selecting a preset inventory or invoking generation when available.
- See `.scratch/phoneme-inventories/issues/01-bundle-100-pregenerated-inventories.md`.
